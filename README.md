Сайт-презентация по дисциплине «Мультимедийные технологии».

## Как открыть у себя

Просто откройте `index.html` двойным кликом. Все библиотеки и шрифты лежат локально, интернет не нужен.

## Как показать сайт по Wi-Fi без интернета

Компьютер и телефон/ноутбук должны быть подключены к одной Wi-Fi сети. На компьютере нужен установленный [Node.js](https://nodejs.org) (проверено на Node 26).

1. Дважды кликните `start-server.bat`.
2. Откройте на компьютере экран с QR-кодом: `http://localhost:8080/qr` (он также открывается ссылкой **«QR для гостей»** в подвале сайта).
3. Покажите этот экран гостям — они наводят камеру телефона на QR-код и сразу открывают сайт. IP-адрес на экране не показывается.
4. Если устройство не сканирует QR, в чёрном окне сервера есть резервные адреса в разделе **«Резервные адреса в локальной сети»**.
5. Если Windows спросит про доступ в сеть — нажмите **«Разрешить»** и выберите **частные сети**.

Интернет при этом не нужен: сайт отдаётся с вашего компьютера. Браузер на главном компьютере откроется автоматически.

QR-код содержит локальный адрес внутри себя — иначе телефон не сможет подключиться. Но на самом экране и в ссылке, которую видят гости, IP-адреса нет. Для показа на проекторе на QR-экране есть кнопка **«На весь экран»**.

### Если другие устройства не открывают сайт

- Запустите `allow-firewall.bat` (он запросит права администратора и добавит правило брандмауэра для портов 8080–8090). Правило разрешает подключения только с устройств в этой же локальной сети и работает при любом профиле сети.
- Проверьте, что устройства в одной подсети (адреса начинаются одинаково, например `192.168.31.x`).
- На некоторых роутерах включена «изоляция клиентов» (AP isolation) — её нужно отключить.
- VPN на компьютере иногда мешает доступу по локальной сети — попробуйте временно отключить.
- Для домашней Wi-Fi сеть лучше переключить в **«Частную»**: Параметры → Сеть и Интернет → Wi-Fi → Свойства сети. Это не обязательно для работы, но безопаснее.

### Остановка

Нажмите `Ctrl+C` в окне сервера или просто закройте окно.

### Ручной запуск

```bash
node server.js
```

Можно указать другой порт: `node server.js 3000`. Если порт занят, сервер сам попробует следующие.

## Что внутри

- тёплый терракотовый 3D-объект на фоне (Three.js), который вращается при скролле и реагирует на курсор; вокруг — латунные орбиты и осколки;
- редакционная палитра: тёплая бумага, глубокий лесной зелёный, терракота и латунь; без неоновых градиентов и «космоса»;
- спокойные заголовки, тонкие кромки карточек, мягкие тени и аккуратная сетка на фоне;
- обновлённый логотип POLY: лесной знак и терракотовая точка, новая favicon;
- кастомный курсор: кольцо и точка, которые реагируют на ссылки, кнопки, карточки и drag-сцены;
- прелоадер с прогрессом, боковой указатель разделов, плавные переходы между страницами и магнитные кнопки;
- кастомная страница 404;
- разделы: основа 3D, пайплайн производства, интерактивное демо полигонов, рендеринг, инструменты, будущее;
- карточки «Основа», «Пайплайн», «Рендеринг» и «Будущее» стали интерактивными: по клику открывается диалог с подробным объяснением;
- интерактивная сфера: три уровня детализации, wireframe, вращение мышью и стрелками;
- карточки инструментов с иконками ведут на отдельные страницы о Blender, Unreal Engine 5, Unity, Cinema 4D, Houdini и Three.js;
- мини-игра «Свет в кадре»: три уровня, перетаскивание света мышью или стрелками, яркость и температура, эталонный кадр, оценка совпадения, звёзды и локальный рекорд;
- QR-экран для гостей: гости сканируют код и открывают сайт по Wi-Fi, IP-адрес на экране не отображается;
- счётчик уникальных посетителей: сохраняется на сервере в `data/visits.json` и не сбрасывается при перезапуске;
- адаптив под телефон, планшет и десктоп, поддержка reduced motion.

## Счётчик посещений

Счётчик работает, когда сайт открыт через `start-server.bat` или `node server.js`. Он считает уникальные браузеры: каждому посетителю выдаётся локальный ID, а сервер хранит количество в `data/visits.json`. При перезапуске сервера значение остаётся прежним.

Чтобы сбросить счётчик, остановите сервер и замените содержимое `data/visits.json` на:

```json
{
  "count": 0,
  "visitors": []
}
```

При открытии сайта напрямую через `file://` счётчик скрыт: без сервера сохранять статистику негде.

## Публикация на GitHub Pages

Сайт полностью статический: HTML, CSS, JS, шрифты и Three.js лежат локально, поэтому его можно опубликовать на GitHub Pages без сборки.

1. Создайте публичный репозиторий на GitHub.
2. Загрузите содержимое папки в корень репозитория — `index.html` должен лежать в корне.
3. Откройте **Settings → Pages**.
4. Выберите **GitHub Actions** (в проекте уже есть workflow `.github/workflows/pages.yml`) или **Deploy from a branch → main → / (root)**.
5. Сайт будет доступен по адресу `https://<username>.github.io/<repo>/`.

Важно: на GitHub Pages не работает `server.js`, поэтому:

- счётчик посещений скрыт (он работает только через локальный `start-server.bat`);
- QR-экран автоматически переключается в режим **«Онлайн-версия»** и кодирует публичный адрес сайта, а не Wi-Fi IP;
- файл `data/visits.json` остаётся в репозитории, но на Pages не обновляется — это нормально.

Локальный запуск и показ по Wi-Fi при этом продолжают работать как раньше.
